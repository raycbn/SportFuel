# NUTRITION_EVIDENCE

Revisión: **2026-08-15**. No se copian textos extensos de las fuentes. Cada regla del motor cita estos identificadores.

## Cómo se usa la evidencia

1. Se priorizan position stands (ACSM, IOC, ISSN) y consensos revisados.
2. Se aplican **rangos**, no dosis universales.
3. Si un hallazgo reciente (p. ej. 90–120 g/h) no es consenso recreativo, se documenta como techo avanzado, no como default.
4. Si no hay evidencia suficiente, **no se inventa** la cifra.

## Qué no se ha usado como regla

- Pérdida de peso o “definición”.
- Protocolos para diabetes, ERC, embarazo o TCA.
- Dosis de cafeína personalizadas (arquitectura lista, sin motor en MVP).
- Comparaciones de marcas de geles como si fueran clínicamente superiores.

## Hidratación y sodio: variabilidad

Las tasas de sudor y el [Na+] del sudor varían entre personas y días. El motor **siempre** muestra un rango, supuestos y avisos. No dice “necesitas exactamente X ml” ni prescribe megadosis de sal.
